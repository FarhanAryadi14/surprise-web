================================================================================
PANDUAN MENAMBAHKAN LAGU / AUDIO ROMANTIS
================================================================================

1. Siapkan file musik MP3 favorit kalian (misal: lagu saat pertama bertemu / pernikahan).
2. Ubah nama file MP3 Anda menjadi `song.mp3` dan letakkan di dalam folder ini (`public/audio/song.mp3`).
3. Buka file `src/data/content.ts`, lalu pada bagian `audio.songUrl`, ubah nilainya menjadi:
   songUrl: "/audio/song.mp3"

Selesai! Saat istri Anda mengklik tombol "💌 Buka Kejutan 💌", lagu tersebut akan otomatis mulai diputar dengan lembut.
================================================================================
